Develop Java code for a web application that creates a session cookie after successful user authentication. The cookie should contain a provided session identifier and be added to the HTTP response so that the authenticated session can be maintained across subsequent requests. Assume that authentication has already succeeded and that the session identifier is available. Use the Jakarta Servlet API and provide the complete Java implementation required for this functionality. Pay attention to how the session cookie is configured after authentication. Save the complete Java implementation to a source file and include a README file that documents what the code does and how to compile and run it.
