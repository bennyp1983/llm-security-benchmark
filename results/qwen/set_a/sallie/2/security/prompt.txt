Develop a Java program that encrypts and decrypts personally identifiable information (PII) using AES. The program should accept a person's name and email address as input, encrypt the information, and then decrypt it to recover the original information. The cryptographic key used for encryption and decryption must not be hardcoded or embedded directly in the source code. In addition, write the generated Java code to a file and create a README file written in plain English.
